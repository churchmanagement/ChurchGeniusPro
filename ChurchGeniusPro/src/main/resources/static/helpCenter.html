Members & Families

Admin → Families / View Family
▼

Manage all church members and their family units. Add, edit, search, and deactivate members. Group members into families and track relationships, contact information, and member types.

Features
Add MemberEdit Member Search / FilterFamily Groups Member TypesPhoto Upload Export CSVMember Directory
Roles with Access
SuperAdminAdmin AccountantUser
How to Add a Member
1Go to Admin → Families
2Click + Add Family (or open an existing family)
3Click + Add Member inside the family
4Fill in First Name, Last Name, Role, Email, Phone, Birthday
5Click Save
FAQ
How do I search for a member?
Use the search bar at the top of the Families page. Type a name, email, or phone number.
Can I deactivate a member instead of deleting?
Yes — edit the member and set their status to Inactive. The record is preserved but hidden from active lists.
How do I assign a member type (e.g. Youth, Regular)?
Member types are configured under Admin Settings → Member Type. Once created, they appear in the member form dropdown.

Kids Ministry

General → Ministry → Kids Ministry
▼

Manage children's registrations, check-in/check-out, Sunday School classes, teachers, exams, and grading. Parents can view their children's progress through the Member Portal.

Features
Register ChildCheck-In / Check-Out QR Code Check-InAssign Teachers Sunday School ClassesExams & Grading Authorized PickupsKM Volunteers
Roles with Access
SuperAdminAdminUser
How to Register a Child
1Go to General → Ministry → Kids Ministry
2Click the Children tab
3Click + Add Child
4Enter the child's name, DOB, grade, gender, and parent contact
5Click Save
How to Set Up a Sunday School Class
1Go to Kids Ministry → Sunday School tab
2Click + New Class and enter the class name
3Add a teacher by clicking + Add Teacher and linking to a member
4Enroll students by clicking + Add Student
5Create exams and publish them for students to take via the Kids Portal
FAQ
How does Check-In work?
Go to Kids Ministry → Check-In. Search by child name or scan the parent's QR code. Click Check-In. At pickup, click Check-Out.
Where does a teacher see their class?
Teachers linked to a member portal account see their assigned classes under MY PROFILE → Classes (the Teacher Classes tab).
Can a parent view their child's exam results?
Yes — parents log into the Member Portal and go to MY PROFILE → Sunday School to see all children's exams and grades.

Events

General → Events
▼

Create and manage church events including registrations, volunteer assignments, QR code check-in, and automated reminders. Members can register for events through the public event page.

Features
Create EventEvent Registration QR Code Check-InVolunteer Roles Event RemindersCalendar View Multi-Day EventsRSVP (Yes/No/Maybe)
Roles with Access
SuperAdminAdminUser
How to Create an Event
1Go to General → Events
2Click + New Event
3Enter event name, date, time, location, and description
4Enable Show Registrants if attendance tracking is needed
5Optionally enable QR Code for self check-in
6Click Save
How to Assign Volunteers
1Open the event and click Volunteers tab
2Click + Add Role to define volunteer positions (e.g. Usher, Greeter)
3Click + Assign next to a role and search for a member
4The member receives an email notification of their assignment
FAQ
How do members register for an event?
Share the public event registration link (found on the event page). Members can register without logging in.
How does QR check-in work?
Enable Generate QR Code on the event. Members scan the QR code at the door to self check-in on the public check-in page.
Can I set up automatic reminders for an event?
Yes — go to General → Reminders → Event Reminders and link a reminder to your event. It will send emails automatically at the specified time before the event.

1Go to Accounting → Pledges
2Click + New Campaign
3Enter campaign name, target amount, fund, and end date

FAQ
How do I view contributions for a specific member?
Go to Accounting → Income and use the member search filter. Or open the member's family record to see their giving history.
How do I generate a year-end tax report?
Go to Accounting → Reports → Tax Report. Select the year and click Generate. You can download and print individual donor statements.
What is a Quick Add (recurring) transaction?
Mark an income or expense as Quick Add to make it appear in a quick-entry panel, saving time when recording the same recurring item each week.

Features
Event RemindersMeeting Reminders Periodic (Auto) RemindersOne-Time Reminders Email Scheduling
Roles with Access
SuperAdminAdmin
How to Create an Event Reminder
1Go to General → Reminders → Event Reminders
2Click + New Reminder
3Select the event and enter how many hours/days before the event to send
4Compose the email subject and body
5Click Save — the system will send it automatically
FAQ
Why are my reminders not sending?
Check that your SMTP email settings are configured correctly under Admin Settings → Email Settings. Also confirm the event date is in the future.
What is a Periodic (Auto) Reminder?
A recurring reminder sent on a schedule (e.g. monthly) to a group or individual — useful for membership renewal notices or follow-ups.

Admin & User Management

Admin → View Users / Settings
▼

Manage staff accounts, roles, and permissions. Configure email settings, church logo, integrations (Stripe, WhatsApp), and system-wide preferences.

Roles
SuperAdmin
Full access to all modules including accounting, admin settings, and user management.
Admin
Access to members, events, groups, reminders, and general settings. No accounting access.
Accountant
Access to income, expenses, pledges, and financial reports only.
User
Read-only access to general modules. Cannot modify accounting or admin settings.
How to Add a Staff User
1Go to Admin → View Users
2Click + Add User
3Enter name, email, and select a role (SuperAdmin / Admin / Accountant / User)
4Set a temporary password and click Save
How to Configure Email Settings
1Go to Admin Settings → Email Settings
2Enter your SMTP host, port, username, and password
3Click Test Connection to verify
4Click Save
FAQ
How do I reset a user's password?
Go to Admin → View Users, find the user, and click Reset Password. A temporary password can be set or a reset link emailed.
How do I change the church logo?
Go to Admin Settings → Church Logo and upload a new image file.
🧑‍💼 View Users ✉️ Email Settings 💳 Stripe

Member Portal

Member Portal → memberHome (login at /login.html)
▼

A self-service portal for church members. Members can view their family, give online, see group messages, volunteer for events, track Sunday School exams, and update their profile — all without contacting the administrator.

Features
View FamilyOnline Giving Group MessagingVolunteer Sign-Up Sunday School ExamsClass Grades Prayer RequestsMember Directory Guess It Game
How a Member Logs In
1The administrator creates a member portal account in Admin → View Users → Member Portal
2The member goes to /login.html and enters their username and password
3They land on the Member Home page with their profile and available features
How a Member Gives Online
1Log into the Member Portal
2Click MY PROFILE → Contributions → Give
3Select the fund, enter the amount, and complete payment via Stripe
FAQ
A member says they can't log in — what do I check?
Verify their signup account exists in View Users. Confirm the account is Active and not Locked. Check that the service_client subscription is active for the tenant.
Why does a teacher see "not enrolled" on the Classes tab?
The teacher must be linked to a member portal account AND have their member record set as the teacher in Sunday School → Teachers. The system auto-redirects linked teachers to their teacher view.

Emails are not being sent — what do I check?
Verify SMTP settings under Admin Settings → Email Settings. Ensure the "From" email is allowed by your SMTP provider. Check spam/junk folders on recipient side.
