Learn how to use Church Genius Pro

Welcome to Church Genius Pro

Church Genius Pro is a complete church management platform. Use the sections below to learn about each feature area and how to get the most out of the application.

👥

Members & Families

  • Go to Admin → Members to add, edit, or search church members.
  • Go to Admin → Families to group members into family units.
  • Use the View Family page to see all members belonging to a family.
  • Member types (e.g. Regular, Youth) can be configured under Admin Settings → Member Type.
💰

Income & Expenses

  • Record tithes, offerings, and donations under Accounting → Income.
  • Log church expenditures under Accounting → Expense.
  • Check the 🔁 indicator on a row to identify recurring (Quick Add) transactions.
  • Configure funds, purposes, and transaction types under Account Settings.
📋

Accounting Reports

  • View income summaries from Accounting Reports → Income Report.
  • View expense summaries from Accounting Reports → Expense Report.
  • Use Date Range Transactions to pull a combined income/expense view for any period.
  • Generate a Year-End Tax Report for annual filing or donor acknowledgement letters.
  • The Financial Report gives a high-level balance overview.
📅

Events & Meetings

  • Create and manage church events under General → Event.
  • View all upcoming events in the Event Calendar.
  • Allow members to register for events via Event Register.
  • Schedule and track meetings under General → Meetings.
  • Meeting categories can be defined under Admin Settings → Category.
🔔

Reminders

  • Set up Event Reminders to automatically notify attendees before an event.
  • Use Periodic Reminders for recurring membership or donation follow-ups.
  • Schedule a specific One-time Reminder for any custom date and time.
  • Configure your outgoing email settings under Admin Settings → Email Settings before enabling reminders.
✉️

Email & Notifications

  • Compose and send emails to individuals, families, or groups from General → Email.
  • Attach files directly to outgoing emails from the compose screen.
  • SMTP settings (host, port, credentials) are configured under Admin Settings → Email Settings.
🖥️

Public Screens & Files

  • Display live church information on a projector or TV via General → Public Screens.
  • Generate and share a secure public screen link without requiring a login.
  • Upload and manage church documents and images under Admin → Files.
⚙️

Admin & Users

  • Manage staff accounts and roles from Admin → View Users.
  • Roles available: SuperAdmin, Admin, Accountant, and User — each with different permissions.
  • Update your church logo from Admin Settings → Logo.
  • Set a daily scripture verse for the dashboard under Admin Settings → Daily Verse.
  • Use the topbar dropdown to switch between linked accounts or update your account settings.
