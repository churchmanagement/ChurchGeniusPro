⚙️

Master Setting

When off, no page is restricted. A web server can't see Wi-Fi names — each network is matched by the IP address/range it presents to the server.

📶

Approved Networks

Add the public IP address(es) or CIDR range(s) each church network uses (one per line). Examples: 203.0.113.7, 10.0.0.0/24.

📄

Restricted Pages

Mark a page Private and choose which approved networks may reach it. Leave all networks unchecked-but-enabled to allow any approved network. Administrators always retain access (logged as an override).
