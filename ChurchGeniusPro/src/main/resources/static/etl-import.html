1 · Start an import run

A run is bound to one church (tenant). Everything you stage or load belongs only to it.

2 · Upload source files

CSV or JSON. Each file becomes a named source table, captured verbatim and profiled. No live data is touched.

3 · Review the column mapping

The matcher suggests a source column for each target. AUTO = high confidence; REVIEW = please check. AI suggestions are always REVIEW — nothing loads until you confirm.

4 · Stage, validate & preview

Transforms run the confirmed mappings into tenant-stamped staging rows, then validation grades every row. Still nothing live.
Target: family

Load to live data

Approving creates a reversible batch. Loading writes the VALID/WARN rows into this church's live family table (INSERT-or-SKIP, tenant-stamped). Duplicates default to SKIP. A whole batch can be rolled back.
